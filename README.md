# Автоматизация бизнес-процессов

Исходный код сайта Василия об автоматизации бизнес-процессов.

- Сайт: <https://autobiz-vb.github.io>
- Платформа: Next.js со статической сборкой
- Публикация: GitHub Actions → GitHub Pages

## Обновление сайта

После сохранения изменений в ветку `main` GitHub автоматически:

1. устанавливает зависимости;
2. выполняет `npm run build:pages`;
3. публикует содержимое каталога `out` на GitHub Pages.

## Локальная проверка

```bash
npm ci
npm run build:pages
```

Форма заявки отправляет данные напрямую в опубликованное веб-приложение Google
Apps Script, поэтому отдельный сервер для GitHub Pages не требуется.
